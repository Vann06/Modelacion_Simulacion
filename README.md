# Implementación de Algoritmos

Este proyecto contiene la implementación de tres algoritmos vistos en clase:

- A*
- Hill Climbing
- Flujo Máximo - Costo Mínimo

Cada algoritmo se aplica a un problema sencillo y puede ejecutarse desde un menú principal.
